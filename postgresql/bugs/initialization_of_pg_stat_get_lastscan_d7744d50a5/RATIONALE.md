# Rationale

File/function: src/backend/utils/adt/pgstatfuncs.c, pg_stat_get_lastscan().

Traces to the single fix.patch hunk in pg_stat_get_lastscan(). In REL_18_6 the function is generated by the
PG_STAT_GET_RELENTRY_TIMESTAMPTZ macro, which returns NULL when the value is 0. I replaced that
macro use with the pre-fix hand-written function. It returns NULL only when there is no tabentry, and it returns
tabentry->lastscan as is otherwise. A relation that has never been scanned therefore reports
1999-12-31 (timestamp 0) instead of NULL.
