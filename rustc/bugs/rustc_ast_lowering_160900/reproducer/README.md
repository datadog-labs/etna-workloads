Restriction paths (`impl(in path)`) that are not ancestors of the item should be diagnosed. The fix does the ancestor check during AST lowering, so those errors come after resolution errors. The injected compiler does the check inside late resolution, so the "can only be restricted to ancestor modules" errors are emitted before an unrelated unresolved-path error (E0433). The reproducer has both kinds of error in one file, and the order of the diagnostics differs between the compilers.
