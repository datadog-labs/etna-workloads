Compiles no_core inline asm with f64 operands in vsreg for powerpc64le (vsx+power8-vector) and prints the generated assembly. The fixed compiler uses the correct little-endian vector lane (the asm sees the register directly, XX lane-fixup becomes a plain register 1/0 reference); the injected compiler uses lane 0, so it emits extra xxspltd/xxswapd shuffles and different register numbers.
