Compiles a no_core thumbv8m test (using the minicore auxiliary) containing `async unsafe extern "cmse-nonsecure-entry" fn f(_: ...)`. The clean compiler bails out of CMSE ABI validation for c-variadic functions, so it reports 4 errors. The injected compiler removes that bail-out and emits an extra, spurious E0798 "`impl Trait` is not allowed" error at the async/variadic function, giving 5 errors.
