Compiles a function with an elided-lifetime reference parameter and an `impl Trait` parameter, triggering E0311. The clean compiler suggests `fn foo<'a>(d: impl Sized + 'a, p: &'a mut ()) ...`; the injected one emits invalid syntax (`fn foo(d: impl Sized + 'a, p: 'a, &'a mut ())`) because the lifetime is inserted at the first generic param (the synthetic impl Trait param) instead of the proper lifetime-suggestion span.
