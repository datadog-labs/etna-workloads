An included expression file (expr.rs) begins with a frontmatter-looking block (`---`, `-`, `---`) followed by `1`. In `include!` in expression context, frontmatter must not be stripped: the clean compiler lexes it as `---(-1)` tokens (a double-negation warning, exit 0). The injected compiler strips it as frontmatter, emitting E0658 "frontmatters are experimental" and an assertion failure, exit 1.
