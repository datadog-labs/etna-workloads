With `use std::collections::{HashMap, self as coll};` and `HashMap` unused, the `unused_imports` autofix should produce a single suggestion that removes only `HashMap` (leaving `{self as coll}`). The injected compiler mishandles `self as …` and emits extra, different removal suggestions (it would produce the non-compiling `use std::collections::self as coll;`). The script prints the suggested replacements from the JSON diagnostics. The clean compiler prints one; the injected compiler prints three.
