A proc-macro crate (pm.rs) defines an attribute macro that prints the spans of its input tokens. It is applied as an inner attribute (#![show]) in the out-of-line module file child.rs, with an outer #[deny(...)] on the mod. On the clean compiler the spans are the real source positions (main.rs:3:1..4:11 tokens individually); on the injected compiler the file-module span preservation is lost, and every token collapses to the single span main.rs:4:1: 4:11.
