Compiles a no_core function taking the address of a local for amdgcn (addrspace(5) alloca + addrspacecast) with -O and prints the alloca, addrspacecast and llvm.lifetime lines of the LLVM IR. On the clean compiler the lifetime intrinsics receive the alloca directly; with the bug, the pointer is not stripped of the addrspacecast, so the IR differs (the lifetime.end call carries a different/nonnull-annotated operand, since the intrinsic is applied through the cast).
