Compiles a `#[no_core]` function returning a `#[repr(C)] struct of five u16` by value for `powerpc64-unknown-linux-musl` (ELFv2, big-endian) with -Copt-level=3 and prints the asm of `read_medium`. The clean compiler returns the aggregate in registers with the expected load/shift sequence (`ld 3, 0(3)` / `sldi 4, ..., 48`); the injected compiler casts the return to a single integer of the aggregate's size, producing different code (`rldicl`/`rldimi`).
