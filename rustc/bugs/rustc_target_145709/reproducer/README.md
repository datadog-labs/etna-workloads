On loongarch64, compiles at opt-level 0 extern "C" functions returning structs with padding ({u8,f64} and an align(64) {f32,f64}) and prints the LLVM IR loads of the return value. The fixed compiler casts the return as separate float/double loads at their field offsets; the injected one loads the whole { float, double } / { i8, double } aggregate from the (smaller or padded) local, reflecting the lost per-field offsets in the LoongArch call-convention code.
