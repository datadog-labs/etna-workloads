Compiles a no_core crate (minicore + main.rs) for arm64ec-pc-windows-msvc with a C-variadic `va_arg::<i128>` read and prints the generated assembly of `read_i128`. The clean compiler treats i128 as passed by reference under the MS x64 ABI (loads an 8-byte pointer slot, then `ldp x0, x1, [ptr]`); the injected compiler reads the 16 bytes directly from the va_list slot (`ldp x0, x1, [x9], #16`), misreading the argument.
