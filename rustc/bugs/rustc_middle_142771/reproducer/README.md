main.rs is a small function compiled with -Zmir-opt-level=4 and -Zdump-mir=SimplifyCfg-final; the script prints the MIR after the final SimplifyCfg merges the goto-chain blocks. A correct compiler keeps the debuginfo (DBG) statements in their original order relative to the merged statements. The injected compiler drops or misplaces them (DBG for _4 and _5 are lost or moved to the end of the block), because merging blocks no longer preserves debuginfos.
