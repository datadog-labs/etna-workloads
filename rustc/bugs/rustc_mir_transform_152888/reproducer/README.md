Compiles the mir-opt test `async_drop_mir_pin.rs` (an `AsyncDrop` impl plus an async fn dropping `[Foo; 1]`) with `-Zvalidate-mir -Zlint-mir -Zmir-opt-level=4`. On the clean compiler it succeeds. On the injected compiler (where `StorageDead(fut)` is added to the shared succ block instead of a fresh block) the async drop glue shim has broken MIR ("StorageLive ... which already has storage"), giving internal compiler errors and exit status 101. The script prints the count of such errors and the exit status.
