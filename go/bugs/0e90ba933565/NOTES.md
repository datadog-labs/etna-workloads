repro.go compares zero-size structs T1{} and T1(T2{}) in a switch. The clean toolchain compiles and prints "equal". The buggy toolchain fails with an internal compile error, "cannot use T2 value as type T1 in assignment". The cause is that walkCompare assigns both operands to one temporary typed like the left operand, but the right operand's OCONVNOP was stripped, so its type no longer matches.
