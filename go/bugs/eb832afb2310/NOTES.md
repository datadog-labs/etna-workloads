The reproducer is the issue63505 test program as repro.go. On go-clean it compiles and runs with exit 0 and no output. On go-buggy it fails with an internal compiler error: "init.0: not lowered: StructMake STRUCT MAP". The injected bug restricts the decompose rules for single-field struct/array to Ptr instead of PtrShaped, so a struct wrapping a map is not lowered when converted to an interface.
